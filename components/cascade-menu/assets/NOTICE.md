# Cascade Menu provenance

The standalone Cascade implementation was authored for Arclen from observed radial-menu behavior, then adapted for Arclen UI's React and HTML delivery. The original Arclen SVG mark was supplied by its owner. No reference-site JavaScript bundle, downloaded mask, original logo, hosted font or external icon path ships in this package. Some wheel geometry, timing and shadow values were measured from the reference; these are documented adaptations, not a claim of an independent visual design. The owner approved public distribution on October 4, 2026.

Source and original assets in this package are provided under Arclen UI's MIT license. Keep this notice with the component.
