# Glyph Funnel

Six ribbons of characters converge on an ember beam. Brush a ribbon or tap the field to disturb the flow. Set the parent height. Tune each ribbon’s flare on either side of the pinch, or hide it. Reduced motion renders a composed still.

## Use

Import the named component from ascii-stream or use the HTML download. The Customize panel lists the same settings accepted by the React component.
