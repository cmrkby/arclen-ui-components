Files opens first. The five panels link to Gmail, Google Calendar, Google Drive, Google Keep and Slack. Each link opens the app in a new tab. Select a heading to open its panel, or select it again to close it. The circular timer pauses the five-second cycle. Arrow keys move between headings, Home and End move to the first and last heading, and Enter or Space selects a panel. Reduced motion turns off cycling and opens the panel immediately.

Each panel has a colour and artwork size in its own settings group. The global artwork scale multiplies each panel’s size. Backplate strength controls the grain and soft silver light behind each icon. Set it to 0% for a flat panel. Changing the colour also adjusts the text for contrast. Panel edits leave the current panel open. Use Opening panel to change the selection.

In React, import AlloyAccordion and pass settings as props, for example `<AlloyAccordion filesColor="#f2bf93" filesScale={1.12} />`. With vanilla JavaScript, import the stylesheet and call `mount(host, { filesColor: "#f2bf93", filesScale: 1.12 })`. The returned instance exposes update, pause, resume and destroy.

Each panel group includes its title, description, link label and destination. Destinations accept HTTP or HTTPS addresses. The canvas is transparent. The bars use charcoal (#1C1C1C) and the open panels use its inset surface (#222222). The +, play and pause controls share the same raised face. The timer draws its progress around the edge. The original black chrome and polished silver icon sets and the licensed Geist font are bundled locally.

Choose Light in Appearance to use white bars, pale grey inset panels and the five silver icons. Match theme switches the icon set with the surfaces. Choose a specific Icon finish to compare both materials on the same surface. The dark and light colour settings are stored separately.

Each panel has its own artwork scale and horizontal and vertical offsets for the expanded view. The layout, typography, button sizes, divider, artwork shadows and hover settings apply across the set. Desktop height is a minimum so larger type has room to wrap. Set Hover movement to zero for stationary artwork. Both themes use the same keyboard and reduced-motion behaviour.
