# Photo Stack Footer

A neighborhood dog-walking footer with five photo prints and a perforated address card. Hover over a print or press and hold it on a touchscreen to read its caption. The address card reveals its sticker the same way. With a keyboard, Tab to a card and press Enter or Space to toggle it. Escape or moving focus away restores its resting position.

## Use

Import `SnapshotFooter` from the React package or install the standalone HTML version. Place it after the main content in normal flow. Its layout follows the footer’s available width. At widths under 810 px, the first print, address card and fourth print share the compact stage. Choose Swipe all photos for a scrollable strip on phones up to 650 px wide. Layout spacing and headline size adapt to the available width.

Use Tweaks to change the pine background, ember accent, brand, booking button, walk photographs, captions, service area and destinations. The example booking address uses the reserved loop.example domain. Design also controls typography, link column width, paper colours, lift timing and the leash mark. Add or remove items within each directory group on the Links tab. Set your booking URL or email and your own navigation and legal destinations before publishing.

## Motion and accessibility

Words enter 50 ms apart on first intersection. The body and each print enter separately. Reduced motion skips the entrances and makes card changes immediate. Without JavaScript the content remains visible, the links work and mouse hover still lifts the prints.
