# Provenance

The procedural shader, modular grain mixer, contour descriptors and interpolation were independently authored for Arclen. Rendered visual observations informed the reconstruction; no reference implementation, reference image texture, third-party shader or commercial asset is included.

This portable package reuses Arclen's original renderer math and adds manifest-derived settings, server markup, document-scoped lifecycle ownership and a React adapter. The core has no runtime dependencies. React is supplied by the consuming application.

The local poster is generated from this package's default procedural artwork. It is not a reference screenshot. No third-party attribution or licence notice is required for the independently authored code and artwork.

Flowing ribbons reuses Arclen’s independently authored structural alternative with its fragment program and geometry equations retained. Flowing blanket is an Arclen-authored soft perimeter field with its own diffuse color mapping and the same original grain mixer. Both share the package’s settings and lifecycle controller. No reference implementation was used.

The ribbons poster remains the lossless WebP encoding of its admitted native Metal phase-zero render at 1440×600 CSS pixels. The blanket poster is captured from the current actual renderer; its creation receipt is retained with the local release evidence. Poster hashes are listed in assets/PROVENANCE.md. Separate catalogue thumbnails are captured from actual shaders and do not alter portable artwork.

The soft perimeter revision follows owner-provided visual observations only. Those study images are not package assets and no reference pixels, textures or implementation were used.

The four relative color-strength controls and normalized palette math are original Arclen code. They reuse the admitted field equations and static grain; default strength 1 retains Original and Ribbons’ prior color paths. The soft perimeter field uses the same role calibration, with its edge and rim placed in the visible portion of its unchanged Gaussian. Its opacity is applied after color/grain grading so the tail retains the chosen hue.
