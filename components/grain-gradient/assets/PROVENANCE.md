# Poster provenance

All three posters are original Arclen procedural artwork, captured from Grain Gradient's own renderer at 1440 × 600 CSS pixels and encoded as lossless WebP without crop, resize or colour edit.

- `poster.webp` SHA-256 `2d745bf6a1c740e34885197061342c7977101ce1dbca62c918e523a497e5d602`.
- `poster-ribbons.webp` SHA-256 `d7ea2942dd518864a4939cf906a8748a15d35a64fd69c604ecae4abb7043f176`.
- `poster-blanket.webp` SHA-256 `77b114c9e9dda3773da8a84e25f3f6e220e7736e6e901121efef7c74fa476b87`.

Posters show the default warm colours with all four strengths at 1. Configured colours and strengths are rendered by JavaScript or the CSS fallback; the posters do not recolour themselves.
