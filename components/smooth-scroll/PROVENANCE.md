# Provenance

Smooth Scroll 2.0.0 contains original Arclen code, interface copy and procedural artwork, authored in November 2026. The colour field and grain use an independently authored static WebGL renderer with a CSS fallback. The arrow is a geometric SVG path. Inter by Rasmus Andersson is bundled under OFL-1.1; see assets/OFL-Inter.txt. There are no runtime dependencies or third-party images. The poster is a capture of the rendered component.
