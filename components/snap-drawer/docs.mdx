# Snap Drawer

A bottom drawer with a short overview, a middle view and a full reading view. Open it from an inline trigger, drag the panel, or use the visible expand and collapse controls.

## Install and use

```sh
npx arclen-ui add snap-drawer
```

Import `SnapDrawer` or its `Component` alias from the installed component directory. The React wrapper imports its stylesheet. The core has no runtime dependencies; the optional wrapper uses your application's React installation.

```tsx
import { SnapDrawer } from './components/snap-drawer';

export default function ProjectDetails() {
  return <SnapDrawer
    title="Project details"
    triggerLabel="View project"
    theme="system"
    snapPoints={['148px', '355px', '100%']}
    initialSnap={0}
  />;
}
```

The package includes its CSS and a local Geist font. Choose `fontFamily="system"` to use your system font. Place the trigger anywhere in normal document flow. The drawer uses a native modal dialog in the document's top layer, so its fixed panel fills the receiving viewport even inside a narrow or transformed container.

## Snap points

Snap values are positive viewport anchors, written as pixels or percentages. They are not visible drawer heights. At a 1,000 px viewport, the default 97% panel is 970 px tall. The 148 px anchor translates it by 852 px, leaving 118 px visible. The 355 px anchor translates it by 645 px. The 100% anchor shows the full panel.

Provide two to five distinct anchors. `initialSnap` indexes your configured list. The component sorts reachable positions and maps your index to the corresponding position. Very low anchors are clamped to keep 96 px of the panel accessible; coincident positions are merged. A viewport shorter than that falls back to one full view.

A slow release chooses the nearest reachable view. A sustained fast upward release opens the highest view; a fast downward release dismisses. Dragging below the midpoint between the lowest view and the closed position also dismisses. Content scrolls at the highest reachable snap, including custom lists that omit 100%. A downward gesture transfers to the panel only at the top of its content. Mouse users can scroll with a wheel or trackpad; dragging a button or link activates that control instead of moving the panel.

## Themes and content

`system` follows the receiving device before and after JavaScript loads. `light` and `dark` use fixed palettes. Choose `custom` to use the seven color settings. The overlay opacity controls its background alpha; Adaptive separately fades the overlay when the panel settles at its highest snap. Constant keeps it dimmed whenever the drawer is open.

Each group's item titles and descriptions must have matching lengths. Empty groups are omitted. All text is escaped. Set `actionHref` to a relative path, hash, HTTP or HTTPS URL to render a same-tab link. Leave it empty for an action button. There is no checkout or payment integration.

The API reference is generated from the package manifest and lists all 45 settings, defaults and bounds. Light, Dark, Short content, Roomy and Custom monochrome are preset setting objects. Preview size, pause and device controls are not exported settings.

## Configured example

```tsx
import { SnapDrawer } from './components/snap-drawer';

export default function ReleaseDetails() {
  return <SnapDrawer
    triggerLabel="View release notes"
    title="Release notes"
    metadata="Version 2.4"
    description="Read the changes before continuing to the full release notes."
    showRating={false}
    contentWidth={560}
    initialSnap={1}
    groupOneTitle="Changes"
    groupOneTitles={['Faster search', 'Clearer settings']}
    groupOneDescriptions={[
      'Search keeps the filters you selected.',
      'Each setting now includes a short explanation.'
    ]}
    groupTwoTitles={[]}
    groupTwoDescriptions={[]}
    showQuote={false}
    actionLabel="Read release notes"
    actionHref="/releases/2.4"
  />;
}
```

## Events and imperative use

```tsx
"use client";
import { SnapDrawer } from './components/snap-drawer';

export default function ActionDetails() {
  return <SnapDrawer
    onOpenChange={open => console.log(open)}
    onSnapChange={index => console.log(index)}
    onAction={event => {
      event.preventDefault();
      console.log(event.detail.settings.title);
    }}
  />;
}
```

Callbacks belong in a React client component. For plain JavaScript, import `mount` and `resolveSettings` from `src/core`. `mount(host, settings)` returns `open()`, `close()`, `snapTo(configuredIndex)`, `update(settings)`, `pause()`, `resume()` and `destroy()`. Updates accept a complete or partial settings object, with omitted fields restored to their defaults.

The host emits `snap-drawer:open-change`, `snap-drawer:snap-change` and a cancelable `snap-drawer:action` event. Preventing the action event keeps the drawer open. Otherwise its button dismisses the drawer. A link follows its URL normally.

## Accessibility and lifecycle

The named dialog contains focus and makes the surrounding page inert. The visible close control receives initial focus. Tab stays among controls that are visible at the current snap. At the highest view, Tab also reaches the named reading region; use Arrow keys, Page Up, Page Down, Home and End to scroll it. Lowering the panel returns focus from that region to Close. Escape closes the drawer and returns focus to its initiating element. If that element was removed, focus returns to the inline trigger, then the host when available. Stacked drawers retain the page lock until the last one closes.

Reduced motion removes programmatic spatial travel. Pointer movement still follows your hand. Pausing settles the active transition and keeps essential controls usable; resuming does not replay it. Hidden documents settle safely. Destroy removes the modal, listeners and timers, restores owned page styles and reveals the readable static content.

Without JavaScript or native modal-dialog support, the content remains in normal flow beside a disabled enhancement trigger. The HTML bundle also includes a loaded poster for the no-JavaScript view. Without Pointer Events, touch gestures and visible keyboard controls remain available. Without `matchMedia`, CSS still follows the system color preference.

## Delivery

React, plain JavaScript and HTML use the same core. Copy the complete package, including CSS, assets and notices. HTML assets use relative URLs and work under a subpath. No external font or runtime request is required.
