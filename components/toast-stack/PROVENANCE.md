# Toast Stack authorship and assets

Toast Stack 1.0.0 is original Arclen UI code and CSS, authored in 2026. It uses platform fonts and has no external requests or runtime asset dependencies. Its crossed-line close mark and twelve-bar CSS loader are original functional drawings.

Four Iconsax V1 Linear status glyphs are integrated into src/core/icons.ts. Exact source and geometry SHA-256 values are recorded in assets/icon-provenance.json. Path geometry is unchanged; enclosing SVG presentation attributes use currentColor and accessible decorative semantics. The glyphs are licensed separately from the component code. Retain the notice and working attribution link described in NOTICE.md.

The component poster depicts the rendered Toast Stack interface. It is a product preview, not reusable gallery artwork.
