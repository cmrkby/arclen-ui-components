# Contour Field asset inventory

The implementation, terrain formulas, gradient-noise implementation, contour extraction, palettes and static SVG terrain are original work authored for Arclen in November 2026. They require no third-party runtime code, fonts, images or media.

The inline fallback is generated by the same original terrain and elevation-contour functions as the canvas. It is decorative. There are no external URLs or media requests.

The poster is a screenshot of Basin with the ivory and sage palette rendered in the built-in browser on November 2, 2026. The browser reported a 1422×800 CSS viewport at device pixel ratio 1.8. The capture was cropped to the measured component rectangle (1422×800 pixels) and exported as WebP without resizing. 68764 bytes; SHA-256 `df96bcaeeb2da7b9127b2865263cbbbd3e563780256511334faba5378570e9f5`.
