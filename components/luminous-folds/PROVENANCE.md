# Provenance

Luminous Folds is original Arclen work. The analytic fold equations, procedural grain, palette, settings and motion were authored for Arclen. The WebGL lifecycle, host controller and React adapter follow Arclen's own Grain Gradient architecture. No third-party implementation, shader, texture, image or runtime dependency is included.

The package poster is a phase-zero capture of the default renderer, converted losslessly to WebP. Its hash is listed in assets/PROVENANCE.md.
