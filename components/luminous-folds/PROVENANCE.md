# Provenance

Luminous Folds uses independently authored analytic fold equations and a stationary procedural grain function. Two owner-supplied still images informed composition only. Their ownership is unknown; the images remain ignored study material and are not included as assets, textures, traced geometry or posters. Motion is original because the stills establish no direction or timing.

The document-scoped WebGL resource lifecycle, dedicated-host controller and thin React adapter reuse Arclen's admitted Grain Gradient architecture. The fold equations, palette and settings are new. No Grain contour tables, reference implementation, third-party shader or runtime dependency is included.

The package poster is a real phase-zero capture of the default renderer, converted losslessly to WebP. Its exact hash is listed in assets/PROVENANCE.md; the local run retains browser capture and creation receipts. Final independent rights admission remains part of release verification.
