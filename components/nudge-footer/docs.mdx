# Sticker Footer

Move the pointer across the coffee stickers or tab to the roast list. Each sticker has separate placement, shadow and spring controls. Pass an asynchronous onSubscribe(email) callback to the React component to connect the form. In demo mode the address stays in the browser.

## Use

Import the named component from nudge-footer or use the HTML download. The Customize panel lists the same settings accepted by the React component.
